# Store Core

نواة متجر إلكتروني عربي (RTL) قابلة لإعادة الاستخدام — Next.js 14 · PostgreSQL · Vercel.

## البدء السريع

```bash
npm install
npm run dev          # يعمل بـ SQLite محليًا بلا إعداد
```

## إنشاء متجر جديد

اقرأ **[NEW_STORE_SETUP.md](./NEW_STORE_SETUP.md)** — دليل من ١٣ خطوة، الوقت المتوقع ٦٥ دقيقة.

## التوثيق الكامل

**[CORE_DOCUMENTATION.md](./CORE_DOCUMENTATION.md)** — ١٥ قسمًا: المعمارية · قاعدة البيانات · الثيمات · الأقسام · التتبّع · النشر.

## ما تعدّله لكل عميل

```
config/store.config.js      الهوية · التواصل · الوحدات
config/theme.config.js      الثيم (٥ جاهزة)
config/content.config.js    النصوص والمحتوى
config/sections.config.js   ترتيب أقسام الصفحات
database/schema.sql         طبّقه على Supabase الجديد
```

**لا تعدّل شيئًا في `lib/` أو `app/` أو `components/`** لتخصيص متجر — كل ما تحتاجه في `config/`.

## ما يوفّره Core

| المجال | التفاصيل |
|---|---|
| المتجر | منتجات · تصنيفات · بحث · فلاتر · سلة · طلب عبر واتساب |
| لوحة التحكم | إدارة كاملة · تحليلات · إعدادات · صفحات قانونية |
| الأداء | كاش موسوم · ترقيم تدريجي · ضغط صور WebP · ١٣ فهرسًا |
| الأمان | RLS · جلسات HMAC · حدود معدّل · ترويسات أمان |
| السيو | خريطة موقع تلقائية · robots · ١٧ نوع شيما |
| التسويق | ١٦ حدث تتبّع · إسناد المصادر · كتالوج منتجات |

## المتطلبات

Node.js 18+ · مشروع Supabase · حساب Vercel (للنشر وتخزين الصور)
